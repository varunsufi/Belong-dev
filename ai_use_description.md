# AI Use Description

I used Codex, an AI coding assistant based on GPT-5, during this assessment.

I used it as a planning and implementation aid across the project. I broke down the requirements into smaller tasks and incrementally gave those smaller tasks to Codex to plan and implement. Some tasks took a few iterations to finalize the plan before implementation. This included help with creating entities, implementing the public authentication APIs, creating middleware for trace IDs, adding request logging, and setting up the Swagger plugin/documentation support.

The AI tool was used to speed up code navigation, structure implementation steps, suggest patterns, and help review the consistency of the work. I remained responsible for the final design decisions, code review, testing, and submitted solution.
